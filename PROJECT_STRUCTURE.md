# Project Folder Guide

| Folder | Purpose |
|---|---|
| `data/raw/` | Original source CSV files. Never edit or overwrite them. |
| `data/interim/` | Temporary outputs created during cleaning and validation. |
| `data/processed/` | Final cleaned datasets used by SQL, Excel and Power BI. |
| `notebooks/` | Step-by-step Jupyter notebooks for loading, cleaning and analysis. |
| `src/data/` | Reusable Python functions for loading and cleaning data. |
| `src/analysis/` | Reusable customer, product, time-series and statistical functions. |
| `src/visualization/` | Reusable chart styling and plotting functions. |
| `sql/schema/` | Database and table-creation scripts. |
| `sql/queries/` | Business-analysis SQL queries. |
| `excel/` | Excel analysis and dashboard files. |
| `powerbi/` | Power BI model and dashboard files. |
| `reports/` | Executive reports, business insights and recommendations. |
| `reports/dashboard_screenshots/` | Final dashboard screenshots for GitHub and LinkedIn. |
| `docs/` | Data dictionary, methodology and supporting documentation. |
| `presentation/` | Final presentation and two-minute project script. |
